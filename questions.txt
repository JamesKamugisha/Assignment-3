(1) Filter 1 and Filter 2 do the same job, but they go through the image in a different order. Filter 1 goes through columns first, while Filter 2 goes through rows first. Both return the number of pixels where the red value is greater than both the green and blue values.
(2) The results show that Filter 2 is faster than Filter 1, especially as the image size gets larger. For the 2048x2048 image, Filter 1 took between about 0.030 and 0.064 seconds, while Filter 2 took between about 0.015 and 0.026 seconds. The times change a little between runs, but the overall pattern stays the same. The graph also shows that the difference between the two filters becomes larger as the image size increases.
(3) The Cachegrind results show that Filter 1 had many more D1 cache misses than Filter 2. Filter 1 had about 1,346,268 D1 misses with a 2.2% miss rate, while Filter 2 had about 394,722 D1 misses with a 0.7% miss rate. This happens because Filter 2 moves through the image row by row, so it accesses nearby memory locations, while Filter 1 jumps through memory by columns. Because Filter 2 uses the cache better, it also runs faster.
